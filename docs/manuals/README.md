# Siemens manuals

Unmodified Siemens documents for the RDF302, included for convenience. They aren't covered by this repository's MIT license, and copyright stays with Siemens. Their notice says they may be duplicated and distributed only with Siemens's express permission. The current versions are available from [Siemens](http://siemens.com/bt/download).

| File | Contents |
|---|---|
| [RDF302_Basic_documentation_en.pdf](RDF302_Basic_documentation_en.pdf) | Full reference (CE1P3079en): functions, parameters and the Modbus register table |
| [RDF302_Datasheet_en.pdf](RDF302_Datasheet_en.pdf) | Datasheet: models, connection terminals and technical data |
| [RDF302_Mounting_instruction_de_en_zh_tr.pdf](RDF302_Mounting_instruction_de_en_zh_tr.pdf) | Mounting and wiring, in German, English, Chinese and Turkish |
| [RDF302_Operating_Instructions_en.pdf](RDF302_Operating_Instructions_en.pdf) | Using the thermostat and setting parameters at the wall, in English |

**The register addresses in the manual are one higher than on the wire.** See [the register reference](../registers.md).
